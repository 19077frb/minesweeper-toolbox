# 扫雷工具箱 / Minesweeper Toolbox

在一个窗口里整理扫雷录像、上传雷网、管理赛事录像与计算成绩和合并 Arbiter 统计 CSV。录像工具处理 `.avf` 文件，无需打开 Excel。

| 你想做什么 | 选择的工具 |
| --- | --- |
| 整理录像名称，找出 PB 和各项前五 | PB/TOP5 |
| 把一个文件夹里的录像批量上传到雷网 | 自动上传录像 |
| 按比赛时间、标识筛选录像并计算成绩 | 赛事录像管理 |
| 合并多台电脑或多个版本的统计 CSV | CSV合并 |

## 启动与基本操作

1. 打开项目文件夹，双击 **启动程序.bat**。
2. 在窗口最上方选择工具，按下文填写输入、输出和选项。
3. 点击对应的开始按钮，查看进度条、计数和日志。
4. 任务结束后，点击“打开结果文件夹”或“打开报告文件夹”查看文件。

首次在新电脑使用时，需要安装 **uv** 并准备 **Python 3.13 或更新版本**。在项目文件夹打开终端，执行以下命令安装依赖并启动：

```powershell
uv sync --locked
uv run main.py
```

已有可用环境时直接双击启动即可。所有文件夹和选项都会自动保存，下次打开恢复，不需要先执行任务。

每个功能页右上方都有“教程”按钮，点击后打开独立教程窗口，介绍操作步骤、每个输入框和选项、进度及输出结果。左侧目录可跳转，正文可滚动和复制；赛事的“成绩记录”页也有教程入口。阅读教程不影响正在运行的任务。

- **递归子文件夹**：勾选后也处理所选文件夹下面的各层子文件夹。
- 可以切换页面查看日志，但同一时间只运行一个工具。
- 点击“取消”后等待任务停止。已完成的改名和复制会保留，取消不会撤销它们。
- **程序不修改录像内容。** PB/TOP5可以修改文件名；上传和赛事筛选不会改动源录像的文件名。

## PB/TOP5：整理录像与筛选最佳成绩

### 怎么操作

1. 点击“添加文件夹”，添加一个或多个录像文件夹；选错后可“移除选中”。
2. 选择输出文件夹。
3. 按需要调整下面的选项，点击“开始整理”。
4. 等待完成，点击“打开结果文件夹”。

| 选项 | 作用 |
| --- | --- |
| 重命名输入录像（加入 STNB） | 默认勾选。修改源录像文件名，加入级别、FL/NF、时间、3BV、3BV/s、STNB和玩家标识；取消后源文件名保持原样 |
| 校验完成度 | 默认关闭，所有能正常读取的录像按100%完成度计算；开启后，只有确认完成的录像参与排名，无法确认的录像会列为“待核验” |
| 额外复制 ALL 文件夹 | 默认关闭。开启后，在每个分类的PB和Top5目录内分别增加一个ALL文件夹，把三级别入选录像直接放在一起，方便网站批量导入 |
| 解析线程 | 控制同时解析录像的数量，通常保留默认值即可 |

### 排名怎么看

- **PB**：同一级别、同一3BV下用时最短的录像。
- **Top5**：Time、3BV/s、STNB分别选前五。Time越小越好，3BV/s和STNB越大越好。
- **FL、NF、ALL**：分别统计插旗类、无旗类以及两类合并后的成绩。
- 初级Top5要求 **3BV≥10**；初级PB没有这个限制。
- 排名以本次输入文件夹中的录像为准，不查询其他电脑或历史Excel。相同内容的副本不会重复占据榜单。

### 结果在哪里

每次运行在输出文件夹下新建一个 `PB_日期时间/`，保留之前的结果：

```text
PB_日期时间/
  FL/    → PB/ 和 Top5/
  NF/    → PB/ 和 Top5/
  ALL/   → PB/ 和 Top5/
```

每类下面再按级别分目录：`Beg`为初级，`Int`为中级，`Exp`为高级，`Cus`为自定义。Top5还会分为 `time`、`bvs`、`stnb` 三项；自定义局不计算STNB。

如需上传到不支持递归文件夹的网站，勾选“额外复制 ALL 文件夹”。例如 `ALL/PB/ALL/` 包含该分类三级别的PB录像，`ALL/Top5/ALL/` 包含三级别各项Top5的合集；FL、NF分类也分别生成对应合集。直接进入所需ALL文件夹后全选录像即可。合集不包含自定义局，同一内容在每个合集内只保留一份，同名不同内容会加后缀保留。

`pb.csv`、`top5.csv` 可查榜单及对应录像路径；`rename_log.csv` 记录改名，`warnings.txt` 记录警告。启用完成度校验后，如有待核验录像，可查看 `needs_review.csv`。

## 自动上传录像：批量上传到雷网

1. 切换到“自动上传录像”。
2. 选择录像输入文件夹；也可点击“使用本次整理结果”，取用本次打开程序后PB/TOP5生成的结果。
3. 输入雷网账号和密码，确认“递归子文件夹”等选项。
4. 点击“开始上传”，结束后点击“打开报告文件夹”。

只上传标准初、中、高级AVF录像，自定义局和其他格式会跳过。上传提交的是原始录像内容；每批相同内容只提交一次，所以可以直接选择含多个PB/Top5副本的结果目录。

默认勾选“跳过本机记录中该账号已上传成功的录像”。这里使用本机历史记录，不是查询网站的全部上传记录；需要再次尝试时可取消勾选。

| 状态 | 含义与处理 |
| --- | --- |
| 上传成功 | 网站明确返回成功 |
| 网站已存在 | 网站已收录该录像，无需再传 |
| 跳过 | 本机已有成功记录、同批重复，或录像类型不支持 |
| 失败 | 查看日志中的原因；账号错误时先修正账号密码 |
| 待确认 | 超时或网站响应无法识别；先到网站核对是否已收录，再决定是否重传 |

上传报告保存在 `data/upload_reports/Upload_日期时间/`。其中 `upload.csv` 是逐录像记录，`summary.json` 是汇总。

上传目标为 `www.saolei.wang`，当前程序使用HTTP接口，传输未加密。账号密码会以普通文本保存在本机 `data/upload_settings.json`，不会写入上传日志；分享项目时不要附带自己的 `data` 文件夹。

## 赛事录像管理：筛选参赛录像与计算成绩

### 填写比赛信息

1. 在“筛选设置”页添加录像输入文件夹，并选择输出文件夹。
2. 填写**比赛名称**，例如 `夏季公开赛` 或 `金羊杯26`。输出根目录直接使用这个名称，不会额外拼接“金羊杯”或届数。
3. 分别填写**初级Top、中级Top、高级Top**，每项支持1–1000局，默认20、12、5；可以按其他赛事的要求调整。
4. 填写开始、结束时间，格式为 `YYYY-MM-DD HH:MM:SS`。区间包含两端。
5. 填写**标识后缀**，例如 `G12345`。程序匹配录像内部玩家标识的末尾，区分大小写，不按录像文件名匹配。
6. “时间依据”通常保留“录像内记录时间”；也可选“文件修改时间（原工具）”。

程序先筛选时间，再解析符合时间区间的录像。使用录像内时间时仅预读头部信息，使用文件修改时间时直接读取文件属性；完成度校验只对其他条件都符合的录像执行。进度中会显示已解析数量及因时间不符而跳过的数量。
7. 点击“开始筛选及计算”。完成后自动进入“成绩记录”。

比赛名称、三级别Top数量及其他选项都会自动保存，重启后恢复。比赛名称用于创建文件夹，不能包含 `/`、`\`、`:` 等文件夹名称不允许的字符。

完成度默认按100%处理；需要检查时勾选“校验完成度”。符合条件的FL、NF合并计分，不再按玩家分别统计。

如需批量导入其他网站，勾选“额外复制 ALL 文件夹”。`参赛录像/ALL/` 平铺三级别全部符合条件的参赛录像，`TopX/ALL/` 平铺各计分榜单入选录像，每个合集按内容去重。

### 哪些录像会被选中

| 级别 | 导出参赛录像的3BV要求 | 计分要求 |
| --- | --- | --- |
| 初级 | 无限制，3BV<10也保留 | 3BV≥10，取设置的初级Top局数 |
| 中级 | 3BV≥30 | 取设置的中级Top局数 |
| 高级 | 3BV≥100 | 取设置的高级Top局数 |

Time、3BV/s、STNB独立排名，同一录像可以进入多个指标榜单。自定义局不纳入。Top数量可配置，3BV门槛与PPP计分公式沿用现有规则；调整Top数量不会自动更换为其他赛事的独立计分公式。

### 如何看成绩和更新门槛

“筛选设置”页的摘要显示 **平均值 / TopX**。右侧是该级别、该指标的第X名成绩，X就是你设置的Top数量。

例如初级Top设置为10，Time显示 `2.85 / 3.20`，表示前10局平均2.85秒，第10名为3.20秒。新的合格录像快于3.20秒就能提升该项平均成绩；3BV/s和STNB则需要高于右侧数值，相等不提升。显示值经过舍入，实际排名使用完整精度。

未满设置的局数时，右侧显示“未满TopX”。平均值暂按设置局数计算：缺少的Time项按初级10秒、中级60秒、高级240秒补位，3BV/s和STNB补零。

“成绩记录”页左侧为初级，右上为中级，右下为高级，行数随各级别Top数量变化。表头 `t`是Time，`b`是3BV/s，`s`是STNB。悬停成绩可查看录像信息，也可调整显示比例、打开HTML报告浏览或打印。

摘要中的 **PPP** 是该级别的综合成绩。底部 `T总局数` 是三级别Time榜单用时总和，`B总局数` 是三级别3BV/s榜单总和，`PPP总局数` 是综合成绩汇总。默认20+12+5时显示 `T37 / B37 / PPP37`；改成5+3+2时显示 `T10 / B10 / PPP10`。

### 保存和重新查看

每次运行保存在“比赛名称”文件夹下的独立时间戳子目录，例如：

```text
输出文件夹/
  夏季公开赛/
    夏季公开赛_20261017_213000_123456/
      参赛录像/
      TopX/
      成绩.html
```

- `参赛录像/`：全部符合条件的参赛录像。
- `TopX/`：按级别和指标分好的计分录像。
- `成绩.html`：可用浏览器查看、打印的成绩表。
- CSV报告：参赛清单、TopX清单及成绩明细；`warnings.txt` 记录异常。
- 启用ALL合集时，进度区显示合集复制数，`all_export.csv` 记录逐份复制结果。

“查看最近成绩”会在当前输出位置、当前比赛名称下查找最新一次结果。查看其他结果，可点击“打开已有成绩…”选择对应的 `成绩.json`，并保留同一目录内的 `TopX.csv`。展示使用报告中记录的比赛名称和Top数量，不受当前表单影响。

## CSV合并：汇总Arbiter统计文件

1. 切换到“CSV合并”，点击“添加CSV文件…”，选择至少两个Arbiter统计CSV。
2. 选择输出CSV文件路径。
3. 选择备份文件夹，或保留默认的 `CSV_backup`（位于输出CSV同目录）。如要用Excel直接打开，可将编码选为“UTF-8 BOM（Excel）”。
4. 点击“开始合并”，完成后点击“打开结果文件夹”。

输入需为UTF-8或UTF-8 BOM的Arbiter统计CSV，前七列为 `Day,Month,Year,Hour,Min,Sec,mode`。

每次合并都强制执行整行去重和排序，没有关闭选项。整行去重只删除所有字段都相同的重复行，不会仅凭相同日期时间删除记录。排序按初级、中级、高级，再按录像时间从早到晚排列。

合并前，在备份文件夹内新建一个 `CSV_时间戳` 文件夹，将每个输入CSV和已有输出CSV放进去，**保留原文件名**。如果输出同时是输入之一，只备份一次。例如：

```text
CSV_backup/
  CSV_20261017_213000_123456/
    stats_csv.csv
    stats_csv_PC.csv
```

每次合并使用独立的时间戳文件夹，保留历史备份。不同来源的CSV若同名，会另放在该批次内的 `同名文件_001/` 等子文件夹中，不更改文件名、不覆盖其他备份。任何一份备份失败都会停止合并，原输出保留。默认备份文件夹随输出CSV的位置变化，也可直接输入或选择其他位置，设置会自动保存。进度区显示备份数量，合并报告记录本次时间戳文件夹和每个源文件对应的备份路径。

合并日志统一保存在程序的 `data/csv_merge_reports/`，点击“打开日志文件夹”即可查看；“打开结果文件夹”查看输出CSV。日志记录合并结果、备份清单及处理计数。

需要查看或操作统计大表时，在“大表”一栏输入Excel文件路径，或点击“选择Excel文件…”，再点击“打开大表”。支持 `.xlsx`、`.xlsm`、`.xls`、`.xlsb`，通过系统默认程序打开。大表路径会自动保存，下次启动可直接打开；这个按钮独立于CSV合并使用，不会自动将CSV写入大表。

## 设置、日志与常见问题

**换电脑后怎么保留设置？** 将原来的 `data/` 文件夹一并复制到新项目目录。它保存各工具选项、文件夹、账号信息、上传历史和解析缓存；换电脑后需检查输入、输出路径是否仍然有效。录像和导出结果要另外复制。

**录像明明成功，为什么显示待核验？** 部分成功录像无法被校验器正确复现，不代表实际失败。确认输入都是成功录像时，可以关闭“校验完成度”，按100%处理；开启校验时，待核验录像不参与排名。

**PB数量为什么比原始录像还多？** FL、NF、ALL独立统计，同一录像可以同时进入其风格分类和ALL，因此总数会累加。

**赛事筛选为什么没有选中某份录像？** 先核对时间依据、时间区间、录像内标识后缀及3BV要求，再查看日志和结果目录的 `warnings.txt`。初级3BV<10的录像可导出，但不会进入初级计分榜单。

**有warning是否代表整批失败？** 不一定。它可能表示榜单局数不足、部分文件无法读取或复制失败。查看具体日志及输出报告判断，已成功处理的结果会保留。
